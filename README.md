# Retail Sales Analysis Dashboard

## Project Overview
This project analyzes retail sales performance using Excel, SQL, and Power BI.

## Tools Used
- Excel
- Power BI
- SQL
- DAX

## Features
- KPI Cards
- Monthly Sales Trend
- Top Products Analysis
- Regional Profit Analysis
- Interactive Slicers

## Workflow
1. Cleaned messy retail sales data
2. Created KPI metrics and pivot tables
3. Built an interactive Power BI dashboard
4. Added slicers and business visuals
